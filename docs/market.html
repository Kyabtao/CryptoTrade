How to read this screen

  • The candle window refreshes after every closed 15m tick — the file is written by the bot itself, so what you see is exactly what it evaluated.
  • Toggle overlays and compare them with the IN▸ / OUT▸ rules on each lesson page.
  • SMA 20/50/200 powers the triple-MA stack (04); EMA 9/21 is the dual-EMA crossover (02); Bollinger 20·2 drives the band fades (06, 29, 41); RSI 14 is the classic oscillator (01, 08, 40).
  • Volume bars are 15m traded volume — look for 2× spikes before reading breakout lessons (28).
About the data. Candles are real Kraken BTC/USDT OHLCV rows stored in docs/candles.json by the scheduled bot run (market data only — no orders, ever). When no candles are recorded yet the screen falls back to the recorded tick closes from history.json.
